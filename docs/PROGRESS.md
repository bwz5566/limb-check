## 第 1 步：手部（2026-10-27）

### 已完成

- **纹身 / 疤痕录用标准引擎**（`limbcheck/marks.py`，标准写在 `configs/policies/marks.yaml`，改标准不改代码）
  - 部位：脖子一律拦截；大臂、小臂按面积 / 颜色；手指以 1 分硬币为参照、≤ 1 处；手背、手掌多处拦截、单处交人工核验；其他部位交人工核验
  - 内容：猛兽（含睡眠 / 闭眼）、鬼神、骷髅、刀具、帮派、暴力图腾、辱骂文字、低俗违禁 → 无论大小拦截；普通文字、符号、看不清 → 人工核验
  - 面积：以身份证 85.6×54 mm（46.2 cm²）为参照；面积大但洗过明显变淡、无攻击性 → 放行；临界（±30%）→ 人工核验
  - 颜色：手指、手背过深拦截；手臂过深交人工核验（"最终以核验为准"）
  - 疤痕：多条整齐平行划痕、严重增生、手背多处陈旧疤痕、疤痕搭配纹身、大面积长条 → 拦截；长条手术刀疤在精细作业岗位拦截、其他岗位核验；单条短小孤立无增生 → 放行
  - 污渍 / 笔迹：提醒清洁后重拍，重拍后仍在 → 人工核验
  - 跨视角合并：手指纹身按"哪只手哪根手指"去重计数，手背面、掌心面分别拍到的也能合并
- **尺寸估算**：大模型给出每处的框（0–1000 相对坐标），用手掌长宽（手部视角）或上臂、前臂长度（身体视角）当尺子换算成厘米；
  估不出比例时用大模型目测的厘米数，再不行用"比身份证 / 硬币小、相近、大"
- **提示词 v2**（`configs/prompts/v2.json`）：纹身、疤痕输出结构化属性；区分纹身、疤痕、污渍、胎记；手部加入手掌 / 手背畸形；v1 保留用于回归对比
- **仲裁**：纹身、疤痕用新的 `policy` 策略，命中拦截条款 → "疑似问题·待人工确认"并列出条款；系统仍不输出最终"不通过"
- **手掌 / 手背完整性**：轮廓复核新增掌面覆盖率（掌面缺一块时关键点仍会给出完整手形）；肤色参照改为多点投票，局部缺失不再把背景当肤色；
  手部检测项要求掌心、手背两个视角都拍到，缺一个就交人工复核
- **新视角**：颈部（左右转头）、双臂外侧近景、双臂内侧近景
- **岗位画像**：四个岗位的纹身、疤痕已按录用标准改为判定模式（书面依据写在 `basis`）；精密装配 `fine_work: true`

- **网页 demo**：新增"露出脖子（左右转头）""双臂近景（外侧 → 内侧）"两个步骤；按手掌 / 小臂关键点估算比例随截图发给大模型；

### 补充（2026-10-27）：筛选严格度 + 高置信度直接判定

- 三档严格度（`configs/strictness.yaml`）：严格（人多）/ 标准 / 宽松（人少），覆盖录用标准里的临界条款和仲裁阈值；
  岗位画像设默认档，网页 demo 开始前可切换，离线评测 `--strictness`

- 指标新增自动判不符合比例、误拦率（合格被自动判不符合）
- 单元测试 120 项通过；网页 demo 严格档端到端跑通

### 已知限制与后续优化空间

- 尺寸靠人体平均尺寸估算，个体差异约 ±15%（面积约 ±30%），所以设了临界区交人工；后续可让候选人把身份证举在纹身旁做精确比例（框架已预留"参照物"来源）
