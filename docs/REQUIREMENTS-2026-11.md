# 《AI面试需求》（2026-11）对照

招聘方 2026-11 提供的《AI面试需求.xlsx》有三个工作表：纹身刀疤案例（录用规则 7 条 + 案例 40 例）、数据采集（采集细则）、其他（问询话术）。
本文逐条对照需求和实现，标出需求里前后不一致、待招聘方确认的地方。案例图保存在使用者电脑的 `docs/requirements_images/`（公司文档加密，未入库）。

## 1. 采集流程（"数据采集"表）

| 需求 | 实现 |
| --- | --- |
| 采集顺序：面部 → 右手背 → 右小臂 → 右大臂 → 左手背 → 左小臂 → 左大臂 → 全身动作视频 | 四个岗位画像的 `steps` 按这个顺序排；中间插入原有的脖子、头发、手部（掌心、手背、指甲、握拳、对捏）步骤，全身动作放在最后 |
| 面部：正对虚线轮廓，保持 3 秒，自动采集；摘口罩帽子；面部明显异常（大面积伤疤）记录复核 | 步骤 `face`：面部 11 个关键点 ≥ 7 个可见、脸宽 ≥ 画面 20%、不转头，保持 3 秒；截脸部图交大模型看疤痕、纹身（面部纹身按标准交人工核验） |
| 手背：掌心朝下自然平放，保持 3 秒；手背完整入框、纹身 / 疤痕可识别 | 步骤 `hand_back_right` / `hand_back_left`：只伸一只手、手背朝镜头、整只手入框、掌长 ≥ 画面高度 12%，保持 3 秒 |
| 小臂：内侧 / 外侧完整展示，保持 3 秒；小臂纹身、自残划痕为重点筛查项 | 步骤 `forearm_*`：肘到腕都在画面里、小臂 ≥ 画面宽度 20%；先掌心和内侧朝镜头，再翻转为手背和外侧，各保持 3 秒，两张图都交大模型 |
| 大臂：完整展示上臂区域，保持 3 秒；大面积纹身、手术疤按标准判定 | 步骤 `upper_arm_*`：肩到肘都在画面里；先自然下垂露外侧，再向侧面抬起 ≥ 60°、掌心朝前露内侧 |
| 全身动作视频：手臂平举 → 下蹲 → 左右高抬腿，约 4 秒；动作不规范需重录 | 原有的侧平举 → 上举、深蹲、原地高抬腿步骤（记录关键点序列做协调性分析），四个岗位都有；没有录制视频 |
| 每项"可重拍 / 手动采集" | 原有的"重拍""跳过当前步骤"按钮；纠正提示播报 3 次仍未做到位按"检测异常，待人工审核"采集当前画面 |

阈值都在 `configs/thresholds.yaml` 的 `close_up` 段。

## 2. 纹身分区规则（"纹身刀疤案例"表第一部分）

每处近景的视角名带左右和部位，服务端以采集步骤为准确定左右（大模型常把画面左右当成身体左右），大模型只说了"手臂"时按这一步拍的部位。
规则在 `configs/policies/marks.yaml` 的 `tattoo.regions`：

| 部位 | 面积参照 | 不录用 | 交人工核验 | 可录用 |
| --- | --- | --- | --- | --- |
| 脖子 | — | 有纹身即不录用（B-01 小花、B-02 星星） | — | — |
| 大臂、小臂 | 身份证 | 面积 ≥ 身份证（B-14）；**洗淡但面积 ≥ 身份证（A-06、A-07，本次改）**；攻击性内容 | 颜色过深（"以现场照片 / 核验为准"）；面积接近身份证 | 面积小于身份证、内容温和（A-08–A-10）；小于身份证的洗后淡痕（A-05） |
| 手指 | 1 分硬币（直径 1.8 cm） | ≥ 2 处（B-08、B-09）；面积 ≥ 硬币（洗淡也不行）；颜色过深 | — | 单处、小于硬币、浅色、无攻击性（规则第 5 条，已确认） |
| 手背 | 身份证 | 多处叠加（B-06）；颜色深（B-05）；面积 ≥ 身份证 | — | 单处小面积浅色无攻击性（同手指，已确认） |
| 手掌 | 身份证 | 同手背 | 单处小面积浅色（未在需求里出现，暂交人工） | — |
| 面部、其他部位 | — | — | 有纹身交人工 | — |

所有部位：牛鬼蛇神、龙虎豹等猛兽（含睡眠 / 闭眼）、骷髅、刀具、帮派 / 恐吓、辱骂文字、涉暴力图腾无论大小都不录用（B-04、B-10–B-13、B-15–B-19）；
普通文字、明显符号交人工核验；最终由 HR 核验（规则第 7 条）。

## 3. 疤痕（"纹身刀疤案例"表第三部分）

原有规则已覆盖全部 10 个案例，未改：多条整齐平行划痕（S01、S02）、长条手术刀疤 + 精细作业（S03、S04、S07）、严重增生（S05）、
手背多处陈旧疤痕（S06）、疤痕搭配纹身（S08）、大面积长条（S09）不录用；单条短小孤立的意外伤疤可录（S10）。

**疤痕问询**（"其他"表第 8 项）：识别到疤痕才触发，无疤痕自动跳过。所有动作做完、大模型复核出结果后，从 4 句温和的问题里随机播报一句，
录下最长 20 秒的口头回答，附在报告里供 HR 参考，不参与自动判定。问题和时长在 `configs/inquiry.yaml`。

"其他"表第 3、4 项的小臂、大臂话术已用作对应步骤的语音提示（按一次一侧改写）。

## 4. 需求里前后不一致、待确认

| 位置 | 内容 | 现在的处理 |
| --- | --- | --- |
| 规则第 5 条 vs 案例 A-11 | 规则写手指纹身小于硬币、颜色浅、无攻击性、1 处可录用；A-11（手指、手背淡淡的小纹身，小于硬币）判不合格；纹身案例依据写"纹身位置仅限大臂、小臂" | 2026-11-05 确认按规则第 5 条可录用（手指、手背 `single: pass`；严格档仍不录用） |
| 案例 A-01–A-04 | 描述都是"面积小于身份证，图案温和无攻击性，正常纹身"，判定却是"不合格不录用"；A-08–A-10 描述相同判"合格" | 规则无法从文字区分，可能与部位或案例图有关，需招聘方说明 |
| 案例 B-06 | 描述"手指上的多个图文"，依据写"手背多处纹身叠加" | 两种情况都判不录用，不影响结果 |
| 案例 S03 | 描述"鱼骨状排列的多条疤痕"，依据写"长条手术刀疤" | 两种情况都判不录用（精细作业岗位） |
| 规则第 4 条 | 颜色过深写在"不予录用"列，说明写"以现场照片 / 核验为准" | 大臂、小臂交人工核验；手指、手背直接按不录用处理 |
