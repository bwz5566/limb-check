# 肢体正常综合判断

把各检测项的仲裁结论和动作步骤的完成情况汇总成一个总结论，显示在报告最上方。
汇总方式全部在 `configs/summary.yaml`（改完运行 `limbcheck export-web-config`，再跑 `pytest`），代码在 `limbcheck/summary.py`。

## 总结论

按顺序判断，第一个满足的生效：

| 总结论 | 条件 | 招聘方怎么做 |
| --- | --- | --- |
| 不符合 | 有不可整改的项目明确不符合（置信度够高，直接判定） | 不录用；候选人可申诉或申请线下复核 |
| 待人工确认 | 有项目"需人工复核"或"疑似问题·待人工确认"，或有动作没完成 | 按卡片里列出的项目看证据后确认 |
| 需重做 | 有画面不清楚、姿势不到位的项目 | 请候选人重新检测相关步骤 |
| 有条件通过 | 只有可整改的项目不符合（默认只有指甲） | 录用，入职前完成整改（卸除美甲、修剪指甲） |
| 通过 | 各项均满足 | 录用 |

- 只汇总判定模式（judge）的检测项；只记录（record_only）的项目列出但不影响总结论。
- **可整改的项目**（`fixable`）：判"不符合"或"疑似问题"时不淘汰，写明整改要求；疑似的标"入职时核对"。
  如果头发也允许入职前染回，在 `fixable` 里加一行 `hair: 入职前需将头发染回自然色`。
- 动作步骤（侧平举、握拳、对捏、随机手势挑战等）没完成 → 所在模块需人工复核。

## 模块

| 模块 | 检测项 | 动作步骤 |
| --- | --- | --- |
| 四肢 | 四肢完整、肢体协调性 | 侧平举 / 上举、交叉摸肩、抬腿、高抬腿、深蹲 |
| 手部 | 手指 / 手掌 / 手背 | 掌心、手背、握拳张开、对捏 |
| 指甲 | 美甲、长度、形状 | 指甲近景 |
| 头发 | 发色、发长 | 头发近景 |
| 纹身 / 疤痕 | 纹身、疤痕 | 露出脖子、双臂近景 |
| 活体 / 防作弊 | 活体 | 随机手势挑战 |

检测范围选"只测某一项"时，只汇总范围内的模块。

## 记录

每次检测的记录（`apps/web-demo/records/`）里有综合结论、各模块结论、整改项目和需人工确认的数量；
统计页（`/records.html`）显示综合结论的分布。
